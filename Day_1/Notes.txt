Web Application: 
----------------
    -> Any Application that will run on browsers is called as a web Applications

Types:
-----
    1.Static web application:
    -------------------------
        -> Any web application that doesn't have functionalities
        -> To build Static web applications we use HTML & CSS
    2.Dynamic web application:
    --------------------------
        -> Any web applications having functionalities is called dynamic web application.
        -> To build dynamic web applications HTML,CSS and JS required

Tags:
----
    -> Tags are the predefined words which are enclosed with both opening and closing angular brackets
    Ex: <h1> 
        <div>
        <p>

Types of Tags:
-------------
    1.Paired Tags:
    --------------
        -> Any tags having both opening and closing tags is called as Paired tags
        Ex: 
            1.All Heading tags
                <h1>heading tag-1</h1>
                <h2>heading tag-2</h2>
                <h3>heading tag-3</h3>
                <h4>heading tag-4</h4>
                <h5>heading tag-5</h5>
                <h6>heading tag-6</h6>
            2.Formatting tags
                i. <b> </b>    -------------------->font bold
                ii. <strong> </strong> ------------>font bold
                iii. <i> </i>   ------------------->font italic
                iv. <em> </em> -------------------->font italic
                v. <mark> </mark> ----------------->highlight the content
                vi. <u> </u> ---------------------->underline
                vii. <sub> </sub> ----------------->subscript
                viii. <sup> </sup> ----------------> superscipt
                ix. <marquee> </marquee> ---------->to scroll the content
                x. <center> </center> ------------->align content to center (only works for block level elements)
                xi. <strick> </strick> ------------>to strike text
            3.Other tags
                <p> , <div> , <span> , all list tags , media tags, semantic tags
